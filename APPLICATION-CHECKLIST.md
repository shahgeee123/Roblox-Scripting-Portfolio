# HiddenDevs Luau Scripter application

## 1. Upload to GitHub

1. Open your `Roblox-Scripting-Portfolio` repository on GitHub. It must be **Public**.
2. Select **Add file → Upload files**, drag in the `Vault-Guardian` folder plus `README.md`, `APPLICATION-CHECKLIST.md` and `STUDIO-CHECKS.md`, then commit.

## 2. Make the demo place

The script has to be the code running in a Roblox place owned by the account named on line 1.

1. In Studio, select **File → New → Baseplate**.
2. Insert a **Script** into **ServerScriptService**, paste in `Vault-Guardian/VaultGuardian.server.luau`, and press **Play** to run the checks in [STUDIO-CHECKS.md](STUDIO-CHECKS.md).
3. Select **File → Publish to Roblox**, then set the experience to **Public** on the Creator Dashboard.

## 3. Submit the direct file link

Open the script on GitHub and copy the address bar. It must point at the file itself:

```
https://github.com/<your-github-name>/Roblox-Scripting-Portfolio/blob/main/Vault-Guardian/VaultGuardian.server.luau
```

| Link | Accepted? |
| --- | --- |
| `…/blob/main/Vault-Guardian/VaultGuardian.server.luau` | Yes: a direct link to a `.luau` file, so GitHub highlights the syntax |
| `https://github.com/<you>/Roblox-Scripting-Portfolio` | No: a repository link, which is why the last application was declined |
| `…/tree/main/Vault-Guardian` | No: a folder link |
| `raw.githubusercontent.com/…` or a paste site | No: raw pastes are not accepted |

Put one link in each input box, with no extra text. If your default branch is not `main`, the link will show your branch name instead.

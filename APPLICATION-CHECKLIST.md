# Publish to GitHub

1. Extract `Roblox-Scripting-Portfolio.zip`.
2. Create a repository named `Roblox-Scripting-Portfolio` on GitHub. Choose Public if reviewers need access.
3. Select **Add file → Upload files** and upload the contents inside the extracted `Roblox-Scripting-Portfolio` folder, preserving all five system folders.
4. Keep `README.md` at the repository root so GitHub displays the portfolio introduction automatically.
5. Commit the files and copy your repository URL for your application.

## Before submitting

- Run the checks in [STUDIO-CHECKS.md](STUDIO-CHECKS.md) and record the actual results.
- Review the current HiddenDevs application requirements.
- Be prepared to explain the code and its tradeoffs, and accurately describe your contribution if asked.
- Share only project code and assets you have permission to publish.
- Add genuine demo videos or screenshots when available.

No license is selected in this package. Choose one if you want to grant reuse rights to material you have permission to license.
